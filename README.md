# 🎮 Summer Tech · Kids Games Hub

A colorful browser arcade built for a **kids summer tech camp** — play games, explore the sprite gallery, and learn to build your own games with AI.

## What's inside

### 🕹️ Arcade Games (8)
Full games with hand-crafted pixel-art sprites, organized into zones:
- **⚔️ Beat 'em Up Arena** — Mad Bunnies vs Cute Cats, Bananas vs Avocados, Sushi Ninjas, Beast Knights, Kids vs The Screens
- **🏆 Sports Zone** — Hoops vs Cleats, Ball Race (מירוץ הכדורים)
- **🚀 Space Arcade** — Nebula Strike

### 🛠️ Build-It Lab (5 mini-games)
Simple games built from scratch — each with a **Hebrew build prompt** so kids can recreate them with AI:
- 🍄 Mario Jump · 🐤 Squeaky Bird · 🦸 Super Hero Fly · ✈️ Fly Simulator · 🧺 Star Catcher

### ✨ Sprite Gallery
Every hero, enemy and boss sprite from the games, in a tappable, zoomable gallery.

## Run locally
```bash
python3 -m http.server 8080
# open http://localhost:8080
```
